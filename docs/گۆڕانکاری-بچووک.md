# گۆڕانکاریی بچووک — نموونەی ئامادە بۆ Claude ـی بەخۆڕایی

پێش هەر داوایەک، فایلی `docs/ARCHITECTURE.md` بدە بە Claude. پاشان یەکێک لەم نموونانە کۆپی بکە و بیگۆڕە بەپێی پێویست.

**گۆڕینی ناونیشان یان لاپەڕەی وانەیەک (بێ دەستکاریکردنی index.html):**
> ئەم فایلە `data/plans.json`ـە. لە پۆلی ١١، وەرزی دووەم، وانەی ٥، ناونیشانەکە بکە بە «...» و لاپەڕەکان بکە بە ١٥٧ تا ١٦٠. ژمارەی `v` لە سەرەوەی فایلەکە یەکێک زیاد بکە. پاشان فایلی تەواو بدەرەوە.

**گواستنەوەی وانەیەک بۆ هەفتەیەکی تر:**
> لە `data/plans.json`، پۆلی ١٠، وەرزی دووەم: وانەی ١٩ بگوازەوە بۆ هەفتەی `M3` (بە گۆڕینی `w`). ژمارەی `v` زیاد بکە.

**زیادکردنی پرسیار:**
> ئەمە دەتوانیت لە ناو ئەپەکەدا بکەیت: «وانە و کەرەستە» ← وانەکە ← پرسیار. هەر دێڕێک بەم شێوەیە بنووسە: «پرسیار | وەڵام».

**زیادکردنی ناوێک:**
> ئەمە لە ناو ئەپەکەدا دەکرێت: «ڕێکخستن و ناوەکان» ← بەشەکە ← زیادکردن. پێویستی بە Claude نییە.

**پاش هەر گۆڕانکارییەک لە GitHub:**
1. لە `sw.js`، ژمارەی `amt-econ-v…` یەکێک زیاد بکە.
2. لە ماڵپەڕی GitHub: فایلەکە بکەرەوە ← ✏️ ← ناوەڕۆکی نوێ دابنێ ← Commit changes.
3. ١–٣ خولەک چاوەڕێ بکە، پاشان ئەپەکە دابخە و دووبارە بیکەرەوە.

**گۆڕینی پاکێجی وانەیەک (پرسیار، سلاید، ڤیدیۆ):**
> فایلی `پاکێجی وانەکان/econ11-t2-07.json` دەگۆڕم (… لێرە بنووسە چی بگۆڕێت …). پاشان لە فۆڵدەری سەرەکیدا `python tools/build_offline.py` جێبەجێ بکە و ژمارەی `C` لە `app/sw.js` زیاد بکە. ئەمانە بنێرە بۆ GitHub: `app/data/packs/*` و `app/data/assets.json` و `app/sw.js`.
> (ئەگەر Python نییە: بە ڕاستەوخۆ ناو `app/data/packs/econ11.json` بگۆڕە، بەهای `"v"`ـی ئەو پاکێجە بگۆڕە، و `"v"`ـی ناو `app/data/packs/index.json`یش بگۆڕە.)
