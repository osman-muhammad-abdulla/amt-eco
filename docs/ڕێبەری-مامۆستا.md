# ڕێبەری مامۆستا — AMT Eco. (کورت)

## یەکەم جار
1. ئەپەکە بکەرەوە (لینکی GitHub Pages، دوای دانانی).
2. **⚙️ پەرەپێدان ← گەڕاندنەوە** و فایلی خۆت هەڵبژێرە: م. عثمان ← `سەرچاوە/AMT-Eco-عثمان.json`، م. سیروان ← `سەرچاوە/AMT-Eco-سیروان.json`. ناوی قوتابییانی پۆلەکانی خۆتی تێدایە.
3. **☁️**: لینکی Apps Script و وشەی نهێنیی خۆت دابنێ. پاشان مۆبایل بە QR ببەستەوە.

## ڕۆژانە
- **ژووری دەرس**: پۆل و بەش هەڵبژێرە، پاشان غیاب، بەشداری، کویز و هەڵسوکەوت تۆمار بکە.
- **وانە و کەرەستە**: وانەکانی وەرزی ١ و ٢ بەپێی پلانی وەزارەت ئامادەن. سلاید، پرسیار و کەرەستەی تێدا زیاد بکە.
- **قرعە 🎡**: قوتابییەک بە هەڕەمەکی هەڵدەبژێرێت و پرسیاری وانەکەی بۆ دێت.
- **📡 ڕاستەوخۆ**: سلایدەکان لەسەر لاپتۆپ پیشان دەدرێن، و مۆبایل دەبێتە ڕیمۆت.
- **پلانی وەرز ← 📄 پلان بۆ ئیدارە**: پلانی ساڵانە و ڕۆژانە وەک PDF.
- **تۆماری نمرە**: نمرەکانی وەرزی یەکەم بە دەست دەنووسرێن.

## کتێب
لە **📖 کتێب**، فایلی PDF ـی کتێبی پۆلەکە هەڵبژێرە. لە فۆڵدەری `سەرچاوە` دان. پاش ئەوە، کلیک لەسەر هەر ژمارەی لاپەڕەیەک لە وانەکاندا ڕاستەوخۆ ئەو لاپەڕەیە دەکاتەوە.

## 📶 بێ ئینتەرنێت
- یەکەم جار ئەپەکە بە ئینتەرنێت بکەرەوە و **٢–٣ خولەک** کراوەی بهێڵەوە. لەو کاتەدا هەموو وانە و وێنەکانی هەر سێ پۆل دادەگیرێن.
- پاشان بێ ئینتەرنێتیش کار دەکات: ناوەکان، غیاب، نمرە، وانەکان، سلاید، پرسیار و چاپکردن.
- ئەمانە ئینتەرنێتیان پێویستە: ڤیدیۆی یوتیوب، هاوکاتکردن لەگەڵ Drive، و دروستکردنی پرسیار بە AI.
- هەر جارێک ئینتەرنێتت هەبوو، ئەپەکە خۆی نوێ دەبێتەوە.
